# Public Disclosure & Intellectual Property Boundary

## 1. Purpose of This Public Evidence Repository

This repository provides a complete, cryptographically verifiable, offline-auditable hardware validation package across two physical quantum processor architectures on Amazon Braket (`22` AWS Braket Tasks, `462` physical executions, `463,800` physical measurement shots, `USD 232.4400` total QPU charges):

1. **Superconducting Gate-Model (`Rigetti Cepheus-1-108Q`, `arn:aws:braket:us-west-1::device/qpu/rigetti/Cepheus-1-108Q`):** `10` AWS Braket `ProgramSet` tasks (`450` compiled circuit executions, `460,800` physical shots, `265.73 seconds` total recorded turnaround, `USD 198.8400`), alongside a 10-workload cross-provider comparison against **`IBM Quantum Heron`** (`ibm_kingston`, `ibm_fez`, `ibm_marrakesh`).
2. **Neutral-Atom Analog Hamiltonian Simulation (`QuEra Aquila`, `arn:aws:braket:us-east-1::device/qpu/quera/Aquila`):** `12` interleaved AWS Braket AHS tasks across two separated batches (`+84.9h` task submission span from `2026-11-16 21:35 UTC` to `2026-11-20 10:29 UTC`, with Round 1 queued between scheduled Aquila operating windows and physically executed `2026-11-20 04:15-04:28 UTC` vs. Round 2 physically executed `2026-11-20 10:32-10:43 UTC` = `+6.2h` physical QPU execution gap; `3,000` physical Rb-87 shots, `USD 33.6000`), evaluating matched-duration (`3.0 us`, `15.70 Mrad/s` peak Rabi drive, `0` experimental `rydbergLocal` terms) global schedules on shared King's-Graph Unit-Disk Graph `MIS` registers (`11A`, `12A`, `13A`).

Every hardware claim in the accompanying report can be verified offline without cloud credentials using [`scripts/verify_braket_campaign.py`](scripts/verify_braket_campaign.py).

## 3. Proprietary Hardware-Aware Optimization Boundary

In accordance with Prometheus Dynamics intellectual property protection standards:
- Proprietary hardware-aware optimization: Prometheus uses circuit/problem structure and device calibration data to guide compilation, pulse scheduling, and execution. Proprietary optimization, compilation, placement, analog control waveforms, and internal synthesis parameters are withheld from this public repository.
- Compiled circuits and analog schedules are identified strictly by their public pipeline designations (`sabre_o3`, `tket`, `prometheus_fresh_candidate`, `prometheus_control_candidate`, `prometheus_candidate`, `sabre_o3_default`, `sabre_o3_matched_budget`, `tket_matched_budget`, `aws_documented_baseline`, and `prometheus_schedule`) and their verifiable SHA-256 cryptographic commitments (`original_private_manifest_sha256 = c6788a9b58803c4b24e59cbcfe0cf9c9830087435c5ff93fd9f55c6bf51687b5` for the Aquila pre-submission manifest).
